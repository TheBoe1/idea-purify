## 验收矩阵

| 场景 | 预期 | 方法 |
| --- | --- | --- |
| Idea 输入与提示词 | 自动补全仍出现预设提示，任意合法内容可输入 | 组件测试与浏览器 |
| Idea 输入校验 | trim 后少于 2 或多于 255，不发送创建请求 | 组件测试 |
| Idea 提交 | 等待锁定，重复点击只有一次 POST；成功清空 | 组件测试与浏览器 |
| Idea 失败/401 | 恢复加载状态并保留草稿；401 仍提示登录 | 回归组件/HTTP 测试 |
| 延迟创建响应 | 换账号或产生新草稿后，旧 POST 成功结果不会清除新草稿/显示旧成功反馈 | 确定性 deferred 组件测试 |
| 配置结构 | 拒绝未知版本、库、组件和危险 props/事件 | 契约与 HTTP 测试 |
| 动作 | 只有 button 的单条固定 click/show-message；无脚本执行 | 契约与渲染测试 |
| 损坏配置 | 局部错误提示，不令整个页面崩溃 | 渲染测试 |
| 文本 | 占位文字/按钮标签/消息中的 HTML 不执行 | 渲染测试与浏览器 |
| 配置权限 | 匿名 401，普通用户读、写 403，管理员创建/更新 | HTTP 和 MySQL smoke |
| 配置持久化 | 创建后重载保留属性，修改后展示新配置 | MySQL smoke 与浏览器 |
| 定义与实例 | 同一已注册定义可产生多个独立实例 | MySQL smoke |
| 数据库异常 | 返回明确安全 503，不能显示保存成功 | HTTP 测试 |
| 路由 | 菜单按元数据排序，管理员入口受角色限制 | 路由测试与浏览器 |
| 原有 Idea | 创建、归档、刷新、个人归属继续有效；旧行不改变 | 原有集成测试与新增 smoke |

npm run test:unit -- --run
npm run test:integration
node --env-file-if-exists=.env.local tests/mysql-component-config-smoke.ts

运行真实数据库 smoke 前先执行 `npm run db:init`，应用新增表。真实 SMTP 尚未配置，不能把本轮进程内替身结果当邮件到达验收。

第一次真实数据库验收发现 MySQL 将 SELECT 别名 `schema` 作为保留字，导致写后回读返回 503；事务回滚，没有保存不完整记录。修复仓库内部别名为 `configSchema` 后真实 smoke 通过，HTTP 的 `schema` 契约保持不变。这项问题只有真实数据库验收能覆盖，内存替身 HTTP 单测不能代替它。

## 浏览器手动步骤

1. 管理员登录，进入「组件配置」，确认只有注册的组件可选。
2. 创建输入实例，修改名称、字段与允许属性，预览中输入。
3. 保存成功后打开「组件」，确认配置出现；刷新确认仍在。
4. 重新加载实例，修改占位文字，保存后展示页重载显示新文字。
5. 创建按钮实例，配置固定提示动作；点击显示文本；HTML 字面量不执行。
6. 切换普通用户，确认可以展示配置，直接打开管理路径不能写入配置。
7. 首页输入「我今天」确认提示，提交 Idea，进入归档和详情，刷新确认保留。
8. 请求失败与非法配置显示错误，其他正常组件仍可使用。

临时数据只按本轮精确 ID 清理。管理员真实账号及既有个人 Idea 不删除。

## 浏览器执行结果

2026-10-13 主代理完成真实浏览器手动流程，验收代理随后对三张截图进行了视觉复核：

- 管理员选择输入框，创建配置、填写必填/minLength/maxlength、预览失焦校验、保存；编辑未保存名称后重新加载，恢复数据库配置。`onInput` 等可执行属性被拒绝。
- 保存按钮实例，普通用户进入组件展示、刷新后读取两个配置。点击按钮显示固定消息，`<script>` 字面文本未被解释成 HTML；预览输入仅在本页面保留。
- 普通用户直接打开 `/admin/components` 被提示无权访问并返回首页；界面不显示管理菜单。
- 首页输入「我今天」出现原有 3 条建议，单字输入被拒绝；提交成功后归档可见、刷新保持，点击进入本人详情。
