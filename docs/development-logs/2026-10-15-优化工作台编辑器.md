## 目标与验收要求

保留现有 Element Plus 全部 API 配置能力，先降低添加、选择与修改组件的操作成本；修复对象字段重复添加覆盖与无断点长内容挤破编辑器的问题。字段超出合同约束时显示错误，保留输入供纠正，不用 maxlength 静默截断。

## 设计决定与依据

- 节点列表一次编辑一个节点，其他节点保留可操作的结构摘要；添加节点后自动展开，避免多份嵌套表单同时挤占空间。
- 节点默认显示常用属性，完整 Props、Events、Slots、Callbacks 与公开引用仍可直接切换。
- 长内容采用局部 min-width: 0、自动换行与响应式布局；标签省略时提供完整 title，编辑值保留完整内容。
- 字符串上限遵循 `shared/contracts/workbench.ts` 的 16000、HTML 8000、安全字段 64 字符等实际合同；不自行降低已有 API 能力。
- Context7 当前无可调用工具，实际参考本地 Element Plus 2.14.5 输入框/表单组件源码与项目类型定义。

## 问题与对应修复

| 级别 | 原问题及代码位置 | 已实现修复 | 减少的负担 |
| --- | --- | --- | --- |
| P0 | `TypedValueEditor.vue:addField` 同名对象字段直接覆盖旧值 | 同名与危险字段即时提示，不执行覆盖；原值保留 | 避免用户重新录入意外丢失的数据 |
| P0 | `TypedValueEditor.vue` 绑定路径经 `parsePath` 删除空段，逐字输入点号会被吞掉 | 当前输入保留空段并报错，继续输入字段后恢复有效 | 可以正常键盘输入多层路径 |
| P0 | 各编辑器 flex/grid 长值与深层结构没有收缩边界 | 局部 min-width、自动换行、深层缩进上限、标题省略加完整 title | 长字段与窄窗口仍能操作；无全局 overflow:hidden |
| P0 | 长文字与 URL 只有整体合同报错 | 按字符串 16000、URL 2048、HTML 8000、样式值 200 提示错误；完整保留输入；长字符串离焦后转多行 | 错误紧邻输入，用户可直接纠正，无静默截断或键入时失焦 |
| P1 | `NodeListEditor.vue` 每个节点的完整嵌套编辑器全部展开 | 一次选中一个编辑；新增自动选中；保留上下移与删除 | 无需在多份完整表单中寻找当前组件 |
| P1 | `NodeEditor.vue` 常用属性必须查 API 搜索后添加 | 默认常用属性页；表单、输入框、按钮等直接编辑；复杂值与全 API 随时可达 | 修改占位文字从搜索、选择、添加、编辑四步降至一次直接编辑 |
